# Análise do Preço da Gasolina

Este repositório contém um projeto desenvolvido em Python no Google Colab para análise do preço da gasolina ao longo do tempo.

O projeto realiza a leitura de uma base de dados em formato CSV, gera um gráfico de linha utilizando a biblioteca Matplotlib e salva tanto o gráfico quanto o código-fonte. Além disso, o repositório é versionado utilizando Git e hospedado no GitHub.
